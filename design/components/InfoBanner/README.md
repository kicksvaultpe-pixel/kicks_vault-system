# InfoBanner
Banner contextual con ícono de línea y texto corto, para explicar el efecto de una opción (Contado/Crédito) o mostrar una acción masiva pendiente.

- `.info-box` + tono: `info-accent` (informativo), `info-orange` (deuda/crédito, `warning-soft`), `info-green`, `info-red`. Texto en `text` 14px; el color va en el fondo suave y en el ícono.
- Ícono SVG de 18px con trazo 2px (mismo set que la navegación). Sin emoji (💵 🗓 📦 🚚 🔒 se reemplazan por íconos).
- `.oc-pago-bar`: barra de acción masiva en `warning-soft` con el total y el botón `btn-yellow`.
- Contado deja de usar violeta: el violeta queda solo para reservas.
